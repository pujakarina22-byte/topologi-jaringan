Modul 01 — Capaian Pembelajaran

🎯 Tujuan Pembelajaran

Setelah mengikuti pembelajaran ini, peserta didik diharapkan mampu menguasai konsep-konsep dasar jaringan komputer dengan baik. Berikut capaian pembelajaran yang akan diraih:

1

Memahami Konsep Jaringan Komputer

Menjelaskan pengertian, fungsi, dan manfaat jaringan komputer dalam kehidupan sehari-hari.

2

Mengidentifikasi Jenis Topologi

Menjelaskan karakteristik topologi Bus, Star, Ring, Mesh, Tree, dan Hybrid beserta kelebihan dan kekurangannya.

Menganalisis Topologi yang Tepat

5

Mengklasifikasikan Kelas IP

Mengidentifikasi Kelas A, B, dan C berdasarkan rentang oktet pertama pada IPv4.

6

Memahami Subnet Mask

Membedakan IP privat dan publik serta memahami fungsi Subnet Mask dalam jaringan.

Modul 02 — Topologi & IP Address

📖 Materi

Pelajari materi melalui tab di bawah ini. Setiap topik dilengkapi penjelasan, ilustrasi, serta kelebihan dan kekurangan.

Topologi jaringan adalah pola penyusunan node (komputer/perangkat) dalam sebuah jaringan. Pemilihan topologi mempengaruhi kinerja, biaya, dan keandalan jaringan. Berikut topologi utama yang perlu kamu ketahui:

🚌

Topologi Bus

Satu kabel utama (backbone) sebagai jalur pusat

Cara Kerja: Semua node terhubung ke satu kabel utama yang disebut backbone. Kedua ujung kabel ditutup dengan terminator untuk mencegah pantulan sinyal. Data dikirim secara broadcast ke seluruh node, dan hanya node tujuan yang menerimanya.

✅ Kelebihan

  • Hemat kabel, biaya murah
  • Instalasi sederhana
  • Cocok untuk jaringan kecil

❌ Kekurangan

  • Kabel utama putus = jaringan lumpuh
  • Sulit deteksi kerusakan
  • Sering terjadi collision
⭐

Topologi Star

Semua node terhubung ke perangkat pusat

Cara Kerja: Setiap node terhubung ke satu perangkat pusat berupa hub atau switch. Semua komunikasi melewati perangkat pusat ini. Topologi star adalah yang paling umum digunakan saat ini karena mudah dikelola.

✅ Kelebihan

  • Mudah deteksi & isolasi kerusakan
  • Kinerja stabil, minim collision
  • Mudah tambah/kurangi node

❌ Kekurangan

  • Bergantung pada perangkat pusat
  • Switch rusak = jaringan lumpuh
  • Borosi kabel lebih banyak
💍

Topologi Ring

Node tersusun membentuk lingkaran

Cara Kerja: Node-node terhubung membentuk lingkaran (cincin). Data mengalir satu arah mengelilingi cincin dari node ke node berikutnya, biasanya menggunakan token untuk mengatur giliran pengiriman.

✅ Kelebihan

  • Aliran data teratur
  • Tidak terjadi collision (token ring)
  • Kinerja seimbang

❌ Kekurangan

  • Satu node rusak bisa ganggu jaringan
  • Sulit tambah/kurangi node
  • Pengiriman lebih lambat
🕸️

Topologi Mesh

Setiap node terhubung ke semua node lain

Cara Kerja: Setiap node terhubung langsung ke semua node lainnya. Untuk N node dibutuhkan N(N-1)/2 jalur koneksi. Jika satu jalur putus, data otomatis mencari jalur alternatif — inilah keunggulan utamanya.

✅ Kelebihan

  • Keandalan sangat tinggi
  • Tidak ada single point of failure
  • Keamanan data lebih baik

❌ Kekurangan

  • Biaya kabel sangat mahal
  • Kompleksitas tinggi
  • Butuh banyak port
🌳

Topologi Tree (Pohon)

Kombinasi Star dan Bus secara hierarkis

Cara Kerja: Topologi tree adalah kombinasi topologi star dan bus. Terdapat node pusat (root) yang terhubung ke node induk, lalu ke node anak. Membentuk struktur hierarki seperti pohon — cocok untuk jaringan berskala besar.

✅ Kelebihan

  • Mudah kelola jaringan bertingkat
  • Cocok untuk jaringan besar
  • Mudah dikembangkan

❌ Kekurangan

  • Root rusak = subtree terganggu
  • Butuh banyak kabel & perangkat
  • Konfigurasi kompleks
🔀

Topologi Hybrid

Gabungan dua atau lebih topologi berbeda

Cara Kerja: Topologi hybrid menggabungkan dua atau lebih topologi berbeda dalam satu jaringan. Contohnya: kumpulan topologi star yang dihubungkan dengan backbone bus. Topologi ini sangat fleksibel dan sering digunakan dalam jaringan nyata berskala besar.

✅ Kelebihan

  • Sangat fleksibel & skalabel
  • Menggabungkan kelebihan topologi lain
  • Cocok untuk jaringan besar

❌ Kekurangan

  • Biaya instalasi & perawatan tinggi
  • Desain dan pengelolaan kompleks
  • Sulit troubleshooting

🔢 Anatomi IPv4

IPv4 (Internet Protocol version 4) adalah alamat logis 32-bit yang digunakan untuk mengidentifikasi perangkat dalam jaringan. Alamat ini ditulis dalam notasi desimal bertitik (dotted decimal notation) yang terdiri dari 4 oktet dipisahkan titik. Setiap oktet bernilai 0–255.

Setiap oktet berisi 8 bit, sehingga total 4 × 8 = 32 bit. Contoh di atas jika dikonversi ke biner: 11000000.10101000.00000001.00000001

📊 Pembagian Kelas IP

IPv4 dibagi menjadi beberapa kelas berdasarkan nilai oktet pertamanya. Setiap kelas memiliki rentang dan jumlah host yang berbeda.

Kelas Oktet Pertama Format Default Jumlah Host Penggunaan
A 1 – 126 N.H.H.H ±16 juta Jaringan sangat besar
B 128 – 191 N.N.H.H ±65 ribu Jaringan menengah
C 192 – 223 N.N.N.H 254 Jaringan kecil (LAN)

N = Network, H = Host. Kelas D (224–239) untuk multicast, Kelas E (240–255) untuk eksperimen.

🔒 Private vs Public IP

Berdasarkan jangkauan aksesnya, IP Address dibedakan menjadi dua:

🔒 Private IP

Digunakan di dalam jaringan lokal (LAN) dan tidak dapat diakses langsung dari internet. Biasanya dialokasikan oleh router menggunakan NAT.

Rentang:
10.0.0.0 – 10.255.255.255
172.16.0.0 – 172.31.255.255
192.168.0.0 – 192.168.255.255

🌍 Public IP

Alamat unik secara global dan dapat diakses langsung dari internet. Diberikan oleh ISP kepada router/modem pelanggan.

Contoh:
8.8.8.8 (Google DNS)
1.1.1.1 (Cloudflare DNS)
202.134.1.10 (DNS Indonesia)

🎭 Fungsi Subnet Mask

Subnet Mask adalah angka 32-bit yang berfungsi untuk membedakan bagian network ID (identitas jaringan) dan bagian host ID (identitas perangkat) dalam sebuah IP Address. Dengan subnet mask, perangkat dapat menentukan apakah IP tujuan berada di jaringan yang sama atau berbeda.

Kelas A 255.0.0.0 /8
Kelas B 255.255.0.0 /16
Kelas C 255.255.255.0 /24
